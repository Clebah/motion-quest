# 👥 Como cadastrar fotos dos Personagens

Organize as fotos criando uma pasta para cada integrante do elenco (até 5 personagens):

```
inputs/personagens/
├── pedro/
│   ├── headshots/        # Coloque de 1 a 5 fotos focadas no rosto (formato .png ou .jpg)
│   │   ├── rosto1.png
│   │   └── rosto2.png
│   └── fullbody/         # Coloque de 1 a 5 fotos de corpo inteiro
│       └── corpo1.png
│
├── ana/                  # Segundo personagem (opcional)
│   ├── headshots/
│   │   └── rosto1.png
│   └── fullbody/
│       └── corpo1.png
```

### Regras do Elenco:
- **Quantidade de personagens:** Até 5.
- **Fotos de Rosto (Headshots):** Mínimo 1, máximo 5 por personagem.
- **Fotos de Corpo Inteiro (Fullbody):** Mínimo 1, máximo 5 por personagem.
- **Formatos suportados:** `.png`, `.jpg`, `.jpeg`, `.webp`.
