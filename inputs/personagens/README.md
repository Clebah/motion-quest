# 👥 Como cadastrar Personagens

Organize as fotos e a descrição criando uma pasta para cada integrante do elenco (até 5 personagens):

```
inputs/personagens/
├── pedro/
│   ├── descricao.txt     # Descrição do personagem (estilo, idade, roupas, traços)
│   ├── headshots/        # 1 a 5 fotos focadas no rosto (.jpg, .png, .webp)
│   │   ├── foto1.jpg
│   │   └── foto2.jpg
│   └── fullbody/         # 1 a 5 fotos de corpo inteiro (.jpg, .png, .webp)
│       └── corpo1.jpg
│
├── ana/                  # Segundo personagem (opcional)
│   ├── descricao.txt
│   ├── headshots/
│   │   └── foto1.jpg
│   └── fullbody/
│       └── corpo1.jpg
```

### O que colocar no `descricao.txt`:
Uma breve descrição das características físicas, estilo e roupas do personagem. A IA utiliza esse texto junto com as fotos para garantir a consistência visual em todas as cenas.
Exemplo:
> *"Mulher de 26 anos, cabelos cacheados escuros, olhos castanhos, vestindo camisa branca e jaqueta de couro preta. Estilo urbano e determinado."*
