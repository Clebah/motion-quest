# Motion Quest

Monorepo para a aplicação **Motion Quest**.

## Estrutura do Projeto

- **`docs/`**: Documentação do sistema e especificações arquiteturais (SDD).
- **`packages/ai-vision/`**: Pacote responsável pelo processamento e análise de visão computacional / IA.
- **`packages/video-render/`**: Pacote responsável pela renderização de vídeo e composições (Remotion).
- **`.tlc/`**: Harness de testes e automação.
